// Project 01

Power-Efficient Approximate Multiplier

Designed an approximate 4:2 compressor-based multiplier to reduce power consumption and hardware complexity for image and video processing applications.

Technologies Used

Verilog HDL · Xilinx Vivado · MATLAB · FPGA

Project Overview

The project focuses on designing an energy-efficient approximate multiplier using approximate 4:2 compressors. Approximation is introduced in the arithmetic circuitry to reduce hardware complexity and power consumption while maintaining acceptable image quality.

Implementation

The approximate compressor architecture was implemented using Verilog HDL and integrated into an 8-bit multiplier. The design was synthesized and evaluated using Xilinx Vivado. MATLAB was used for image processing and quality analysis.

 0: begin

 ca=0; s=1;
 end
 2: begin
 if((a & b) || (c & d)) begin

// Project 02

Digital Clock with Automated Charging

Designed a digital clock with an HH:MM:SS display and automated charging functionality for practical embedded applications.

Technologies Used

Verilog HDL · Xilinx Vivado · FPGA

Project Overview

This project implements a digital clock capable of displaying hours, minutes, and seconds in HH:MM:SS format. The design also includes an automated charging mechanism for practical embedded applications.

Implementation

The digital clock logic was designed using Verilog HDL and implemented using FPGA-based digital design tools. The clock continuously counts seconds, minutes, and hours and updates the display accordingly.

Code


#include <LiquidCrystal.h>

// LCD pins: RS, EN, D4, D5, D6, D7
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

// Charging control
const int chargePin = 8;

// Battery/charging input
const int batteryPin = A0;

int hours = 0;
int minutes = 0;
int seconds = 0;

unsigned long previousMillis = 0;

void setup()
{
    lcd.begin(16, 2);

    pinMode(chargePin, OUTPUT);

    digitalWrite(chargePin, LOW);

    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("Digital Clock");

    delay(1000);
    lcd.clear();
}

void loop()
{
    // Generate one-second clock
    if (millis() - previousMillis >= 1000)
    {
        previousMillis = millis();

        seconds++;

        if (seconds >= 60)
        {
            seconds = 0;
            minutes++;
        }

        if (minutes >= 60)
        {
            minutes = 0;
            hours++;
        }

        if (hours >= 24)
        {
            hours = 0;
        }
    }

    // Display HH:MM:SS
    lcd.setCursor(0, 0);
    lcd.print("Time: ");

    if (hours < 10)
        lcd.print("0");

    lcd.print(hours);
    lcd.print(":");

    if (minutes < 10)
        lcd.print("0");

    lcd.print(minutes);
    lcd.print(":");

    if (seconds < 10)
        lcd.print("0");

    lcd.print(seconds);

    // Read battery level
    int batteryValue = analogRead(batteryPin);

    // Automatic charging control
    // Example threshold; adjust according to your circuit
    if (batteryValue < 500)
    {
        digitalWrite(chargePin, HIGH);

        lcd.setCursor(0, 1);
        lcd.print("Charging ON     ");
    }
    else
    {
        digitalWrite(chargePin, LOW);

        lcd.setCursor(0, 1);
        lcd.print("Charging OFF    ");
    }
}

// Project 04

Automatic Plant Watering System using Arduino

Developed an Arduino-based automatic plant watering system to provide controlled watering and improve water management for plants.

Technologies Used

Arduino UNO · Embedded C · Arduino IDE

Project Overview

This project focuses on automating the watering process for plants using an Arduino UNO. The system controls the watering mechanism according to the programmed control logic, reducing the need for manual watering.

Implementation

The control logic was developed using embedded C and implemented on the Arduino UNO. The Arduino processes the input conditions and controls the watering mechanism accordingly.

Code



// Automatic Plant Watering System
// Arduino UNO

const int pumpPin = 8;

// Watering duration: 5 seconds
const unsigned long wateringTime = 5000;

// Watering interval: 1 minute
const unsigned long wateringInterval = 60000;

unsigned long previousTime = 0;

void setup()
{
    pinMode(pumpPin, OUTPUT);

    // Pump initially OFF
    digitalWrite(pumpPin, LOW);
}

void loop()
{
    unsigned long currentTime = millis();

    // Start watering after the specified interval
    if (currentTime - previousTime >= wateringInterval)
    {
        previousTime = currentTime;

        // Turn ON water pump
        digitalWrite(pumpPin, HIGH);

        delay(wateringTime);

        // Turn OFF water pump
        digitalWrite(pumpPin, LOW);
    }
}
